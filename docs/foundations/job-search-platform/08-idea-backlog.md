# Idea Backlog

Capture candidate enhancements for search quality, user experience, and automation.

## Product Ideas

- Guided search presets for common targets like TPM, Staff PM, and platform engineering.
- Smart company targeting with include and exclude lists.
- Search explainability panel that summarizes ranking factors.
- Search history and saved-search collections.
- Geo-intent assistant that suggests nearby market alternatives.

## UX Ideas

- Two-pane search workspace: facets left, live results right.
- Result cards with confidence and rationale tags.
- Zero-results rescue mode suggesting relaxed filters.
- Quick compare mode for up to three jobs.
- Multi-select actions for resume and outreach generation.

## Data and Ranking Ideas

- Synonym expansion for role taxonomy (TPM, Technical Program Manager).
- Title normalization and seniority extraction.
- Salary normalization across currency and cadence.
- Relevance blending of text, freshness, and user preference fit.
- Duplicate detection across cross-posted roles.

## Source Strategy Ideas

- Source health dashboard and connector scorecards.
- Adapter blueprint kits for ATS families like Workday, Greenhouse, and Lever.
- Source reliability SLA and auto-disable rules for failing connectors.
- Consent-aware workflow for optional apply/resume actions.

## Platform Ideas

- Feature flags for rapid experimentation.
- Search query analytics for product feedback loops.
- Internal benchmark dataset for ranking regression checks.
- Decision log integration with release notes.

## Prioritization Rubric

Use this scoring on each idea:

- User impact (1-5)
- Delivery effort (1-5)
- Risk (1-5)
- Strategic alignment (1-5)

Total score = user impact + strategic alignment - effort - risk

## Initial Candidates for Next Iteration

1. Search filter panel with required fields and saved presets.
2. Dedicated search endpoint with structured query payload.
3. Result ranking explanation labels.
4. Source profile scorecards for top-priority integrations.
