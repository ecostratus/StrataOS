## Weighted Score Formula

Weighted score =

- 0.25 * relevance quality
- 0.20 * data freshness
- 0.15 * data completeness
- 0.10 * parse stability
- 0.10 * integration complexity
- 0.10 * compliance confidence
- 0.10 * operational reliability

## Outcome Bands

- 4.0 to 5.0: High priority integration
- 3.0 to 3.9: Pilot with controls
- 2.0 to 2.9: Defer and monitor
- 0.0 to 1.9: Reject for now
