# Terms and Compliance Checklist

Use this checklist before enabling any new source adapter.

## Required Checks

- Terms of service reviewed and date recorded.
- Explicit confirmation that intended use is permitted.
- Scraping policy reviewed if non-API ingestion is planned.
- Rate-limit and anti-abuse expectations documented.
- Personal data handling constraints captured.
- Attribution requirements captured.
- Data retention constraints captured.
- Regional or jurisdiction constraints captured.

## Apply and Resume Automation Checks

- Resume upload automation permitted.
- Automated apply flow permitted.
- Bot or scripted interaction policy reviewed.
- User consent and auditability requirements documented.
