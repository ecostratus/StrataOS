# Source Profiles

This directory contains source-level research profiles for job and recruiter data integrations.

## Files

- source-profile-template.md
- source-scorecard-template.md
- terms-and-compliance-checklist.md
- profiles/

## Usage

1. Copy source-profile-template.md into profiles/<source-name>.md.
2. Fill access model, terms constraints, payload fields, and reliability notes.
3. Score the source using source-scorecard-template.md fields.
4. Add any legal or policy constraints from terms-and-compliance-checklist.md.

## Review Cadence

- P1 sources: monthly
- P2 sources: quarterly
- P3 sources: semi-annually
